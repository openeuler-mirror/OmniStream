## 测试验证

1. 进入Flink安装目录下的bin目录，并启动Flink。

    ```bash
    cd $FLINK_HOME/bin/ && ./start-cluster.sh
    ```

2. 启动sql-client后，进行测试。

    ```bash
    ./sql-client.sh
    ```

3. 在命令行中输入以下内容。

    ```sql
    SELECT 'Hello, Flink!';
    ```

    可以正常输出结果即安装正常。
